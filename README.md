# FindiT-OnCampus
A lost and found Platform.
**FindIt** is a web-based platform that helps campus communities report lost and found items, making it easier to reconnect belongings with their owners.

## Features
- Report lost and found items.
- Browse and search item reports.
- Filter reports by campus, status, and category.
- Edit or delete your own reports.
- Mark items as recovered.

## Tech Stack
- HTML
- CSS
- JavaScript
- Supabase
